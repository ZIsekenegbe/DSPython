# Python for Data Science

This repository contains projects from a **Python for Data Science** course, focused on learning how data science is actually used in practice.

Across these projects, the emphasis was on gaining knowledge through the use of practical data sets, familiarizing myself with important Python libraries, implementing different task sorting algorithms, regression analysis, and classification algorithms.  

## What I Focused On
- Using Python to explore and understand data
- Cleaning and preparing datasets that are messy with missing rows and delimiter issues
- Finding patterns through visualization and analysis
- Building models when they’re useful (and understanding when they aren’t)

Note: some of what was learned conflicted with other courses

## Tools Used
Most projects I used rely on:
- Python
- pandas and NumPy
- matplotlib / seaborn
- scikit-learn 

Note: includes handy troubleshooting with the notebook application used

Other libraries are included where they made sense for the problem.

## Projects
This repository includes **five projects**, each designed to build practical data science skills, and one capstone project in place of the final exam.
  
While the datasets and goals vary, most projects follow a similar process:
1. Understanding the data and the question
2. Cleaning and preprocessing
3. Exploring patterns and relationships
4. Applying analytical or modeling techniques
5. Interpreting results and limitations

Each project folder includes code, outputs, and brief notes on what was done and why in one pdf as required by the course instructor.

## Objective
These projects reflect how I approach data problems, using a question-first approach. Over time, the goal is to prioritize clarity in code. The capstone project encapsulated everything learned over the semester, utilizing a provided data set to compare classification methods. I also borrowed knowledge from other courses I took (Applied Machine Learning and Statistical Modelling). 


## Final Note
Although this work was completed for a course, the goal throughout was to build habits and workflows that translate beyond the classroom and into real-world data analysis.
